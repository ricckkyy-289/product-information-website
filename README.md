# InfoSpec — Multi-Page Product Information Website

A clean, multi-page **Product Information Website** where every feature has its own dedicated HTML page.

## Pages Included
1. `index.html` — **Home Page**: Explains the website's purpose, links to each section page, and highlights featured products.
2. `products.html` — **Product Catalog Page**: Searchable and filterable directory of all products.
3. `product-details.html` — **Product Details Page**: Full specification table, box contents, and product switcher (`?id=...`).
4. `compare.html` — **Compare Page**: Side-by-side specification comparison between any two products.
5. `manuals.html` — **Manuals & Warranty Page**: User guides, safety compliance sheets, and product FAQs.
6. `verify.html` — **Verify Product Page**: Serial number authenticity lookup and product information inquiry form.

## Customizing Your Products
Edit `js/data.js` to add or update products—all 6 pages read from that single file automatically.
